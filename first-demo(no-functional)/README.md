# AllerFlow (MVP)

Prototipo funcional para gestion de alergenos, intolerancias y operativa de sala/cocina.

## Requisitos previos
- Node.js 18 o superior
- npm 9 o superior

## Instalar
```
npm install
```

## Ejecutar en local
```
npm run dev
```

La app de frontend corre en el puerto 5173 y el backend en el puerto 5174.

## Resetear datos y volver a seed
```
npm run reset
```

## Semilla inicial
Para aplicar la semilla inicial sin reiniciar todo el entorno:
```
npm run seed
```
